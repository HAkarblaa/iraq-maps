# موقع خرائط العراق للكيثوب

موقع مستقل مُجهّز من ملف m.html المرسل، مع مدخل index.html ومكتبات محلية داخل vendor. الخريطة والتضاريس والحدود والمسارات وبيانات الطائرات تستند إلى الخدمات الخارجية المستخدمة في المصدر وتحتاج اتصال إنترنت ودعم WebGL في المتصفح.

## الرفع

1. أنشئ مستودع GitHub عامًا باسم iraq-maps أو اسم تختاره.
2. فك ضغط الحزمة وافتح مجلد iraq-maps-github.
3. من Add file → Upload files ارفع محتويات المجلد إلى جذر المستودع. حافظ على مجلدي vendor وlicenses وبنية الملفات.
4. اضغط Commit changes.
5. افتح Settings → Pages، واختر Deploy from a branch ثم main ثم /(root)، واضغط Save.
6. انتظر نجاح النشر، وافتح الرابط الظاهر في صفحة Pages وجرّب الخريطة.

لا تحتاج إلى Node أو عملية بناء لتشغيل الموقع. ارفع الملفات والمجلدات بعد فك الضغط. بعد النشر يمكن استخدام رابط الموقع لاحقًا لإعداد تطبيق أندرويد.

## التجهيز المنفّذ

- إعادة تسمية صفحة الدخول إلى index.html.
- تضمين MapLibre GL JS 5.6.2 ومظهره محليًا.
- تصحيح تحميل دعم العربية في MapLibre عبر setRTLTextPlugin، وتضمين إضافة RTL 0.3.0 من مسارها الصحيح.
- تصحيح مكتبة osmtogeojson من رابط إصدار 3.0.0 غير المتاح إلى نسخة 3.0.0-beta.5 المتاحة، وتضمينها محليًا.
- تحسين رسالة تعذّر تهيئة الخريطة بدل بقاء حالة التحميل ظاهرة.

الخدمات العامة المستخدمة تشمل OpenFreeMap وOpenStreetMap/Overpass وCARTO وOSRM وOpenSky. توفر بعض طبقات المعلومات يتوقف على استجابة هذه الخدمات وحدود استخدامها. بيانات السكان والمساحات والملاحظات النصية المضمّنة مأخوذة من الملف الأصلي وليست تحديثًا آنيًا.

تراخيص المكتبات محفوظة في licenses. إشعارات نسب بيانات الخرائط للخدمات موجودة في المصدر.

## التحقق

تم فحص صياغة سكربتات الصفحة والمكتبات، ومراجع الملفات المحلية، وتفرّد معرّفات عناصر الواجهة. فُتحت الواجهة في متصفح المعاينة، لكن تهيئة WebGL تعذّرت لأن الرسومات معطّلة في هذه البيئة، لذلك لم يُتحقق من رسم الخريطة أو تشغيل طبقاتها تفاعليًا هنا. جرّب رابط Pages في متصفحك بعد النشر.
